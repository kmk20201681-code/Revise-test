## 3. 오류 수정 보고

### 결함 1

| 항목 | 작성 내용 |
|---|---|
| 결함 ID | BUG-01 |
| 선택자 | `.con` |
| 문제 선언 | `max-width: var(--containner);` — 선언된 변수 `--container`와 이름이 다름 |
| 화면 증상 | `max-width`가 무효 처리되어 넓은 화면에서 콘텐츠 최대 폭이 적용되지 않고 컨테이너가 화면 폭까지 늘어남 |
| 진단 방법 | `root.css`에는 `--container`만 선언되어 있음을 확인하고, Computed에서 `.con`의 유효한 `max-width`가 적용되지 않는 원인을 대조함 |
| 수정 선언 | 필요 수정: `max-width: var(--container);` / 현재 제출본에는 미반영 |
| 수정 전/후 증빙 | 스크린샷 또는 URL 없음 |

제출본에서 `.site-header`에 `display: flex; flex-direction: row;`를 추가했으나, 이 변경은 콘텐츠 최대 폭을 결정하는 `.con`의 변수 오탈자를 해결하지 않는다.

### 결함 2

| 항목 | 작성 내용 |
|---|---|
| 결함 ID | BUG-02 |
| 선택자 | `.grid-5` |
| 문제 선언 | `grid-template-columns: repeat(5 1fr);` — 반복 횟수와 트랙 크기 사이 쉼표가 빠짐 |
| 화면 증상 | 선언이 무효 처리되어 BEST PICKS가 의도한 5단 Grid로 배치되지 않음 |
| 진단 방법 | Grid/Styles에서 `grid-template-columns`가 무효 처리되는 것을 확인하고 `repeat()` 문법을 점검함 |
| 수정 선언 | 필요 수정: `display: grid; grid-template-columns: repeat(5, 1fr);` / 현재 제출본에는 미반영 |
| 수정 전/후 증빙 | 스크린샷 또는 URL 없음 |

제출본은 `display: grid`를 주석 처리하고 `display: flex; flex-direction: row;`로 변경했다. 이 방식에서는 1024/768/480px의 `grid-template-columns` 반응형 규칙이 동작하지 않으므로 과제에서 요구한 Grid 수정으로 볼 수 없다.

### 결함 3

| 항목 | 작성 내용 |
|---|---|
| 결함 ID | BUG-03 |
| 선택자 | `body` 및 `media.css`의 `header, body, footer` |
| 문제 선언 | 기본 규칙의 `min-width: 1600px;` 때문에 1600px 미만 화면에서 문서 전체가 뷰포트보다 넓어짐 |
| 화면 증상 | 태블릿·모바일에서 페이지 전체 가로 스크롤이 발생함 |
| 진단 방법 | 1600px 미만에서 `body`의 Computed `min-width`와 `scrollWidth`/`clientWidth`를 비교하고 기본 규칙과 미디어쿼리를 추적함 |
| 수정 선언 | 필요 수정: `body`의 `min-width: 1600px;`와 미디어쿼리에 추가한 `header, body, footer`의 고정 `min-width`를 제거 / 현재 제출본에는 미반영 |
| 수정 전/후 증빙 | 스크린샷 또는 URL 없음 |

현재 제출본은 1024/768/480px 구간마다 해당 너비의 `min-width`를 다시 지정했다. 특히 구간 사이 너비와 480px 미만 화면에서는 요소의 최소 폭이 뷰포트보다 커질 수 있어 가로 스크롤 원인이 남는다.
